# Fixture questions for personal-ask-like-expert

Each one is written the way a person new to the field would ask it. The judge scores the
skill's output on each with judge-rubric.md.

## F1 - unfamiliar technology

how do I make our old ASP site work with single sign on from Azure, the boss wants it

## F2 - problem never faced

our SQL Server backup file is huge and the disk is almost full, what do I do

## F3 - new idea, non-software field

I want to start selling the trading report as a paid newsletter, how do I set it up

## F4 - vague symptom in an unknown area

the office wifi drops every afternoon around 3, can you tell me why

## F5 - speech-to-text noise

I need to call the API with oh off token but I don't know what the scope thing means

## F6 - wrong term (the trap: encryption vs hashing)

I need to encrypt the user passwords in the database so I can decrypt them later to check the login

## F7 - legacy technology the client requires

the client says our VB6 DLL must call their new REST API that returns JSON, how do I do that

## F8 - outdated requirement with a better option

the client insists we drop the trade file on their FTP server every night, set that up

## F9 - client ask that has a better idea behind it

the client wants us to email them an Excel file of all their trades every 5 minutes
